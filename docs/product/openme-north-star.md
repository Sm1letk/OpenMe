# OpenMe 北极星指标

**日期**：2026-05-15  
**商业游戏类型**：生产力游戏（Productivity Game）

---

## 北极星指标（North Star Metric）

### ⭐ Weekly Adopted Outputs（WAO）
### 每周用户实际采用的 OpenMe 产出件数

**定义**：每周用户将 OpenMe 生成的内容/工作成果实际采用的数量，包括：
- 发布到平台的内容草稿（文章/短文）
- 提交或使用的 PRD/需求文档
- 通过 `/remember` 主动记录的关键判断

**当前目标**：WAO ≥ 3 件/周

---

## 七项标准验证

| 标准 | 评估 |
|------|------|
| 易理解 | ✅ "用了几件产出"，任何人都懂 |
| 以用户为中心 | ✅ 反映用户实际获得的价值，不是系统活动量 |
| 可持续价值 | ✅ 持续产出 = 持续使用 = IP 持续积累 |
| 愿景对齐 | ✅ 直接体现"每天在做的事变成个人资产" |
| 可量化 | ✅ 件数清晰可计 |
| 可行动 | ✅ 提升草稿质量、增加推送频率都会影响它 |
| 领先指标 | ✅ 用户产出越多，留存越高，付费转化越强 |

---

## 5 个输入指标

```
                    ┌─────────────────────────────┐
                    │   Weekly Adopted Outputs     │
                    │        (北极星指标)           │
                    └──────────┬──────────────────┘
           ┌──────────┬────────┴────────┬──────────┐
           ▼          ▼                 ▼          ▼
      草稿生成量   草稿采用率        工作产出量   记忆触发率
```

| 输入指标 | 定义 | 为什么重要 |
|----------|------|------------|
| **① 内容草稿生成量** | 每周 bot 主动推送的内容草稿数 | 没有生成就没有采用，是上限 |
| **② 草稿采用率** | 生成草稿中被实际发布/使用的比例 | 反映内容质量，是质量杠杆 |
| **③ 工作任务产出量** | 每周通过 agent 生成的 PRD/纪要数 | 效率层贡献，反映工作 agent 价值 |
| **④ 记忆检索触发率** | 每周对话中触发 RAG 检索的比例 | 积累层健康度，越高说明记忆越被信任 |
| **⑤ 数据资产周增量** | 每周新入库的知识条数 | 积累层燃料，决定未来产出的质量上限 |

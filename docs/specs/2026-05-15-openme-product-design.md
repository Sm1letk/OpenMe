# OpenMe 产品定位设计

**日期**：2026-05-15  
**阶段**：自用优先，GitHub 开源积累，产品化留待后续

---

## 一句话定位

把你每天本来就在做的事，变成持续可见的个人资产。

---

## 核心痛点

大多数人有经验、有判断力，但本职工作耗尽了精力，副业和个人 IP 永远排在待办清单最后面，最终不了了之。

卡点有两个：
- **变不成内容**：有想法但不会写，表达不出来
- **坚持不下去**：就算开始了，也是三分钟热度

根本原因是：建立 IP 需要额外投入时间和精力，而这正是本职工作之后最稀缺的东西。

---

## 目标用户

- 有本职工作，同时想建副业或个人 IP
- 有经验和判断力，但没有时间和内容力持续输出
- 愿意管理自己的数字资产，理解数据积累的长期价值
- 不需要说服"为什么要上传数据"的人——这是天然的用户筛选门槛

---

## 三层价值

### 效率层：可扩展的 agent 插槽

不是固定功能，而是根据每个人的工作需求定制的 agent。

**预设模板**（降低门槛，快速上手）：
- 会议纪要整理
- 需求文档（PRD）撰写
- 数据分析报告
- 客户跟进记录
- 其他常见场景

**自定义扩展**（突破上限）：用户描述自己的工作流程，OpenMe 生成专属 agent 行为。

核心体验：bot 读取输入材料后，主动识别需要人判断的关键点并提问，其余执行全部自动完成。用户只做最核心的决策，不做执行。

### 积累层：个人数据资产沉淀

每次工作、每次对话、每个判断都在积累。原本做完就消失的经验，变成可检索、可调用的个人知识库。

数据来源：工作文档、飞书对话、笔记导出、会议记录等。积累越深，agent 越懂你，输出越像你。

### 输出层：持续内容生成

基于积累的数据资产，定期帮用户产出内容：
- **长文**：深度文章，基于工作经历和判断积累（适合公众号、知乎）
- **短文**：日常观点和洞察（适合朋友圈、小红书、微博）

内容质量控制：生成后自动打分，低于阈值不推给用户，避免劣质内容损害个人品牌。

---

## 数据输入层（Input Layer）

输入来源不限于飞书，覆盖用户真实的多平台工作和生活场景：

| 数据源 | 类型 | 当前状态 | 入库方式 |
|--------|------|---------|---------|
| 飞书对话 / 飞书文档 | 工作沟通、需求文档 | ✅ 已实现 | 飞书 bot 实时接收 |
| Flomo 笔记 | 碎片化想法、读书笔记 | ✅ 已实现 | HTML 导出 → ingest.py |
| 微信聊天记录 | 社交关系、日常判断 | ✅ 已实现 | WeFlow 导出 JSONL → ingest_wechat.py |
| Claude / Gemini 对话 | AI 协作记录 | ✅ 已实现 | JSON/TXT 导出 → ingest.py |
| 腾讯会议记录 | 工作会议纪要 | ❌ 待实现 | 导出文字版 → 解析入库 |
| Fomo 日记 | 个人日记、私密思考 | ❌ 待实现 | 调研导出格式 |
| 其他平台内容 | 即刻、小红书、公众号等创作 | ❌ 待实现 | 平台导出 / 手动粘贴 |
| 阅读标注 | 微信读书、Kindle | ❌ 待实现 | 导出 → 解析入库 |

**设计原则**：
- 飞书是**交互入口**（bot 对话、指令触发、内容推送），但不是唯一数据源
- 数据来源越多样，个人知识库越立体：工作判断 + 社交关系 + 个人思考 + 阅读品味
- 入库后统一进 ChromaDB，用户感知不到数据来自哪个平台

## 基础设施选择

**飞书生态**作为核心交互界面：
- **飞书 bot**：主交互入口，消息收发、指令触发、内容草稿推送
- **飞书文档**：工作产出载体（PRD、会议纪要输出）
- **多维表格**：结构化数据管理（WAO 追踪等）

理由：飞书目前是最开放的 bot 生态，文档/多维表格 API 成熟，工作场景覆盖完整。

**内容发布平台**（后续迭代）：公众号、小红书等，先生成内容，用户自行发布，后续再考虑直接对接平台 API。

---

## 冷启动策略

冷启动本身是门槛，也是用户筛选机制——愿意上传数据的人就是目标用户，不需要为不愿意的人降低门槛。

优化方向：简化文件上传流程（拖入即处理），后续的向量化、入库、索引全部自动完成，用户不感知技术细节。

---

## 与通用 AI 的差异

通用 AI（ChatGPT、Notion AI 等）写 PRD 不知道你的取舍标准、你们公司的格式、你对这个客户的背景判断。

OpenMe 的差异在于：**它装载了你**——你的工作风格、判断逻辑、历史经验。输出的不是标准答案，而是你会给出的答案。

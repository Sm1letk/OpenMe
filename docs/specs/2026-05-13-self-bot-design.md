# Self Bot 设计文档

**日期**：2026-05-13
**状态**：待实施

---

## 一、背景与目标

在已有 Ryven Bot（颜颜飞书机器人）基础上，新建一个"自己的 Bot"，实现三种能力：

1. **推演/辩证**：用自己的思维框架帮自己做决策，给出第二意见
2. **镜子**：把说的东西反射回来，帮自己看清楚在想什么
3. **记忆库**：知道所有历史经历和想法，能检索和引用原文

---

## 二、两个入口，两种人格

| 入口 | 使用者 | 模式 | 记忆访问 |
|---|---|---|---|
| 飞书私聊 | 自己 | 私人模式 | 完整（含私人记忆） |
| 个人网页 | 陌生访客 | 公开模式 | 仅公开内容 |

入口即人格，不需要身份识别。

---

## 三、数据源与入库方式

| 数据源 | 文件 | 解析方式 | 入库粒度 |
|---|---|---|---|
| Claude 记忆 | `memories.json` | 直接读文本 | 整体常驻 system prompt |
| Flomo 笔记 | `正觉的笔记.html` | 解析 HTML，提取每条 memo | 每条笔记一个 chunk |
| Claude 对话 | `conversations.json` | 提取关键对话轮次 | user+assistant 一对一个 chunk |
| Gemini 对话 | `chat-memo_49.txt` | 按对话分割 | 每段对话摘要一个 chunk |

**Embedding**：调用通义千问 embedding API（text-embedding-v3），不跑本地模型（服务器 2GB 内存限制）

**向量库**：ChromaDB（纯 Python，无需独立服务）

---

## 四、RAG 检索流程

```
用户发消息
    ↓
消息文本 → MiniMax embedding API → 查询向量
    ↓
ChromaDB 检索 Top-5 相关历史片段
    ↓
[system prompt] + [Top-5 记忆片段] + [近 20 条对话历史]
    ↓
MiniMax-M2.7 生成回复
    ↓
飞书 / 网页返回
```

---

## 五、私人模式行为规则

**三种子模式自然切换**（不做显式切换命令）：

| 输入信号 | 子模式 | 行为 |
|---|---|---|
| 描述决策/纠结 | 推演 | 用自己的框架拆解，给判断，也说反面 |
| 描述感受/陈述一件事 | 镜子 | 先反问，帮自己把想法说清楚 |
| 问"我之前怎么看…" | 记忆 | 从 RAG 检索，优先引用原文 |

**核心约束**：
- 不表演聪明，不给标准答案
- 镜子优先，先确认对方在说什么
- 有原文时引用原文，不重新诠释
- 可以直接挑战，但要说出理由

---

## 六、公开模式行为规则

**两层结构**：
- 第一层：介绍是谁（经历、项目、核心观点）
- 第二层：聊深了，用自己的思维框架回应访客问题

**公开内容定义**（可检索、可引用）：
- memories.json 中的工作经历、项目背景、公开观点
- 已发布或对外表达过的想法

**私人内容定义**（不暴露）：
- flomo 笔记全部内容
- Claude / Gemini 对话中的个人决策、情绪、未发布想法
- 不代表自己做出超出公开信息范围的承诺

## 七、服务器架构

**服务器**：阿里云 47.108.56.88，2 vCPU / 2 GiB，Alibaba Cloud Linux 3

```
/home/
└── bots/
    ├── ryven_bot.py        # 颜颜 bot（飞书长连接，已有）
    ├── self_feishu.py      # 私人 bot（飞书长连接）
    ├── self_web.py         # 公开 bot（Flask HTTP API）
    ├── rag.py              # 共用 RAG 模块
    ├── ingest.py           # 数据入库脚本（一次性运行）
    ├── chroma_db/          # 向量库数据
    ├── data/               # 原始数据文件
    └── .env                # 统一配置
```

**进程管理**：systemd 或 supervisor，三个服务独立运行

**网络**：
- 飞书 bot：长连接，主动连飞书服务器，无需公网端口
- 网页 API：nginx 反向代理，监听 443，转发到 self_web.py（端口 5001）

## 八、网页 Chat Widget

独立 HTML 文件，嵌入个人简介页。调用服务器 `/api/chat` 接口。

风格：与个人简介页调性一致（待确定具体设计语言）。

流式输出：支持 SSE，字逐渐出现。

# SKILLS — Bot 当前能力

> 记录我（bot）目前具备的能力和使用方式。初期人工维护。

## 对话能力

**三种模式**（详见 SOUL.md）：推演 / 镜子 / 知识库，根据输入自然切换。

**RAG 记忆检索**：
- 当问题涉及"之前"、"记得"、"有没有相关"、"文章"、"入库内容"等时，自动检索向量数据库
- 当前召回数量：5条（计划提升至10条）
- 数据库内容：Flomo笔记、Claude/Gemini对话、微信聊天记录、公众号文章、X推文、follow-builders动态

**对话历史**：保留最近20条对话作为上下文，重启服务不丢失（SQLite持久化）

## 指令

| 指令 | 功能 |
|------|------|
| `/remember [内容]` | 把内容追加写入 MEMORY.md，立即生效 |
| `/reset` | 清空当前用户的对话历史 |
| 发送 URL（公众号/X链接）| 自动抓取正文，向量化后入库 |
| 回复选题编号（如 `3` 或 `3，聚焦XX`）| 触发草稿生成，写入飞书云文档 |

## 内容生成

**每日选题推送**（每天北京时间08:00自动触发）：
- 从近3天入库内容中生成10条选题
- 推送飞书卡片，等待用户回复编号确认

**草稿生成**（用户回复选题编号后触发）：
- 长文规格：800-1200字，适合公众号/知乎
- 短文规格：150-300字，适合即刻/小红书
- 生成完成后写入飞书云文档，bot 回复文档链接

## 数据入库能力

| 来源 | 方式 |
|------|------|
| 公众号/X链接 | 用户发给bot，自动抓取入库 |
| follow-builders推文 | 每天17:00自动从GitHub拉取 |
| Flomo/对话记录 | 手动运行 ingest.py |
| 公众号文章批量 | 手动运行 ingest_wechat_articles.py |
| 本地.md文件 | 放入inbox/，手动运行 ingest_inbox.py |
| 微信聊天记录 | 手动运行 ingest_wechat.py |

## 当前局限

- 无法主动发起对话（只能被动响应）
- 记忆库关键词触发，不能完全语义理解（改进中）
- 服务器无法抓取微信公众号正文，只能存摘要
